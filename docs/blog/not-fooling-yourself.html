How Not to Fool Yourself

Verification discipline & reproducibility in a competition-bot campaign. ← back to project

TL;DR. Over a months-long campaign we produced roughly nine results that looked like wins and weren't. The most valuable thing we built was not a model — it was the discipline that caught them, plus the reproducibility that let us trust, rebuild, and back up what we had. Two halves of not fooling yourself: a gate that survives replication, and a setup that survives a disk wipe.

Part 1 — The verification gate (a single test lies)

Our recurring failure mode has a name here: the proxy that reverses. A change looks great on a cheap metric, then evaporates the moment you measure what you care about:

  • Held-out accuracy ≠ play strength. A 256-channel imitation scored 0.767 top-1 vs the incumbent's 0.736 — then lost by ~37 pts/game head-to-head. The highest-accuracy architecture we tried didn't win more games.
  • "+2.3/g" → −10/g. A best-response RL run looked positive at small N; at large N it was ten points/game below baseline.
  • The no-op that scored exactly 0.000. A "tie" to the decimal — because a deploy bug silently loaded the base weights. The A/B was fake; the giveaway was an edge of exactly zero.
  • +1.78/g that dissolved under replication. Our latest "first thing to beat the incumbent" held at +1.78/g on one seed family — then, across sibling models, scattered from −11 to +1.7, centered near parity, seat-asymmetric. The positives were the lucky tail.

What stops these from reaching a conclusion is a gate built to be hard to fool:

  • Bias-correction, calibrated to zero. Duplicate self-play (same shuffles, seats rotated) minus a matched incumbent-vs-incumbent run on identical walls. Non-negotiable: incumbent-vs-itself must read +0.000/g.
  • A no-op-trap proof every run — distinct weight hash, param count, non-zero behavioral diff. An exact 0.000 edge is a bug, not a tie.
  • Two seed families, both must pass — kills the "+3.1 in one family, −2.4 in the other" artifact.
  • Per-seat reporting — +6 in seat A and −2 in seat B is a coin flip, not a +2 candidate.
  • Replication over cherry-picking — one winner is a hypothesis; eight siblings consistently winning is a finding. Scatter around zero means the winner was noise.
  • Real games as the gold standard — the local simulator is the filter, never the verdict. Even a careful local gate has reversed against the real field.

Part 2 — Reproducibility

The eval gap. For weeks we judged changes against proxy opponents we built — and everything read "parity," because a strong bot saturates a weak pool and the metric goes blind. The fix wasn't a better model; it was an eval that could see: play the real field, read the real logs. Your result is only as trustworthy as the eval that produced it.

The disk wipe. A rented box was lost and took the cooked data with it — and we couldn't reproduce our own flagship model, because its recipe lived in a shell script on a machine that no longer existed. The lessons, now permanent:

  • Code in version control, not on the box. Boxes are cattle; the repo is the record.
  • A model card per artifact — git tracks code, not the (code × data × command × seed) → weights mapping. That mapping is what you lose. Each model now has a card: weights hash, architecture, every ordered stage with its data hash + full command, and the gate/real-field numbers.
  • Big artifacts in durable object storage, hash-named — datasets & weights to a hub, sha256-verified, so a box death loses nothing.
  • Automate the stamp — manual discipline fails; a wrapper that auto-writes the manifest doesn't.

The meta-lesson

The headline result is a negative one: against supervised variants, several flavors of RL, search, distillation, ensembles, defense, capacity, and auxiliary objectives, the incumbent is at its achievable ceiling — and the gap to the top step is variance among near-equal strong players, not a fixable skill deficit. That is only a trustworthy conclusion because of the two halves above. A negative result done sloppily is indistinguishable from "we didn't try hard enough." Done with a gate that survives replication, an eval that measures the real thing, and a setup you can rebuild from scratch — it's a finding you can stand behind. The methodology was the asset.
